A home screen widget with our logo and the family table. Tap it to open the recipes. It comes in three sizes and takes about two minutes to set up on an iPhone.

Small, medium and large

Set it up

  1. Install Scriptable from the App Store. It is free, and it is what lets an iPhone show custom widgets.

  2. Tap Copy the script below.

  3. Open Scriptable, tap +, paste, and name it Casa de Ouellette. Tap Done.

  4. Long-press your home screen, tap Edit, then Add Widget. Choose Scriptable and pick a size.

  5. Long-press the new widget, tap Edit Widget, and set Script to Casa de Ouellette.

// Casa de Ouellette — home screen widget for Scriptable.
// The artwork lives on the website, so updating it there updates every widget.
const BASE = "https://casa-de-ouellette.netlify.app/";
const family = config.widgetFamily || "medium";
const size = family === "small" ? "small" : (family === "large" || family === "extraLarge") ? "large" : "medium";

const fm = FileManager.local();
const saved = fm.joinPath(fm.documentsDirectory(), "casa-widget-" + size + ".png");
let art = null;
try {
  art = await new Request(BASE + "widget/" + size + ".png").loadImage();
  fm.writeImage(saved, art);
} catch (e) {
  if (fm.fileExists(saved)) art = fm.readImage(saved);
}

const widget = new ListWidget();
widget.backgroundColor = new Color("#f7f5ee");
widget.url = BASE;
if (art) {
  widget.backgroundImage = art;
  widget.addSpacer();
} else {
  const t = widget.addText("Casa de Ouellette");
  t.font = new Font("Georgia-Bold", 16);
  t.textColor = new Color("#2f3a2c");
}
widget.refreshAfterDate = new Date(Date.now() + 6 * 3600 * 1000);

if (config.runsInWidget) Script.setWidget(widget);
else await widget.presentMedium();
Script.complete();

The artwork is loaded from this site and saved on the phone, so the widget keeps working offline. If the picture ever changes here, widgets pick it up on their next refresh.
